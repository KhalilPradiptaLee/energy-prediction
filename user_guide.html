Dashboard Prediksi Input Data User Guide
CARA MENGGUNAKAN WEBSITE

Dashboard:

  1. Anda dapat melihat grafik data hasil prediksi tentang pemakaian tertinggi di hari apa dalam rentang waktu seminggu.
  2. Anda dapat melihat ringkasan total pemakaian dalam rentang waktu seminggu.
  3. Anda dapat melihat rata-rata pemakaian bahan bakar dalam rentang waktu seminggu.
  4. Anda akan diberikan catatan/notifikasi mengenai hal pemakaian bahan bakar dalam waktu seminggu (Contoh: pemakaian lebih tinggi daripada minggu kemarin).

Prediksi:

  1. Masukkan tanggal maksimal untuk penggunaan bahan bakar yang ingin diprediksi, maksimal 7 hari (Contoh: jika hari ini tanggal 1 April maka maksimalnya tanggal 8 April).
  2. Tekan “mulai prediksi” untuk memulai prediksi dari bahan bakar.
  3. Hasil prediksi akan muncul di bawah.
  4. Prediksi ini dilakukan berdasarkan hari selanjutnya.

Input Data:

  1. Masukkan tanggal berapa dan berapa liter terpakai dalam hari tersebut.
  2. Tekan “Tambah Data” untuk menambahkan data.
  3. Anda juga dapat melakukan unduh data.
